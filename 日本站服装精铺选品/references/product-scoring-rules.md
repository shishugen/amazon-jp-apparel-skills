# 100 分评分规则

评分由 `scripts/analyze.py` 自动算，本文档是口径说明。改脚本前先改这里，保持一致。

## 权重

| 维度 | 满分 |
|---|---:|
| 全年需求稳定性 | 25 |
| 市场竞争难度 | 25 |
| 利润空间 | 20 |
| 产品差异化空间 | 20 |
| FBA 库存及退货风险 | 10 |
| **合计** | **100** |

## 1. 全年稳定性（25）

见 `seasonality-analysis.md`。按月度 CV 分档：25 / 20 / 11 / 4；数据不足 8。

## 2. 竞争难度（25）

从 25 分起扣：

| 条件 | 扣分 |
|---|---:|
| TOP10 销量占比 > 55% | −8 |
| TOP10 销量占比 40%–55% | −4 |
| 中位评论数 > 200 | −7 |
| 中位评论数 100–200 | −4 |
| 中位评论数 50–100 | −2 |
| 品牌 HHI > 2500 | −4 |
| 卖家 HHI > 2500 | −3 |
| 任一竞品 `广告竞争` > 2 | −3 |

下限 0，上限 25。

## 3. 利润空间（20）

按 `params.min_net_profit_jpy`（默认 500）为基准 T：

| 单件净利 | 得分 |
|---|---:|
| ≥ 1.5T | 20 |
| ≥ T | 16 |
| ≥ 0.7T | 10 |
| > 0 | 5 |
| ≤ 0 / 价格缺失 | 0 |

## 4. 差异化空间（20）

```text
score = 8
      + min(6, 6 × 低评论竞品占比)
      + 4 × (1 − min(TOP10占比, 1))
      + 2 （若近180天新品数 > 0）
clamp(0, 20)
```

低评论代表新卖家能切进去；TOP10 占比低代表头部没垄断；新品能卖动代表市场对新进入者开放。

## 5. 库存及退货风险（10）

从 10 分起扣：

| 条件 | 扣分 |
|---|---:|
| CV > 50% | −4 |
| CV 30%–50% | −2 |
| 有效月份 < 6 | −3 |
| 样本平均退货率 > 8% | −3 |
| 有变体的竞品占比 > 70% | −2 |

下限 0，上限 10。**变体多扣分**：尺码颜色多会推高库存和退货风险。

## 等级

| 总分 | 等级 | 动作 |
|---|---|---|
| 80–100 | A级 / 优先开发 | 直接进首批采购评估 |
| 70–79 | B级 / 可以测试 | 小批量测试，优化价格/关键词 |
| 60–69 | C级 / 观察 | 有缺口，暂不投钱 |
| < 60 | 淘汰 | 不投采购资金 |

## 精铺模式的两个例外

1. **月销 50 件是目标，不是硬淘汰线。** 月销 30 件但竞争小、利润好、全年稳，仍保留为潜力候选。
2. **小市场也能进候选池。** 样本总销量不大，但只要头部不垄断、评论少、需求稳定，就值得小批量测试。
