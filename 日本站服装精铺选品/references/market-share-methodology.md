# 市场占比分析方法

## 原则

只看关键词搜索量会漏掉市场结构。必须看**整个细分市场的份额分布**：谁在赚钱、头部是否垄断、新卖家有没有缝。

所有指标基于用户导出的样本竞品，报告里统一叫「样本市场份额」。**不要写成日本站全市场份额。**

## 指标与公式

设某细分市场有 n 个竞品，月销量 `s_i`，总收入 `r_i`：

| 指标 | 公式 | 含义 |
|---|---|---|
| 样本总销量 | `Σ s_i` | 样本盘子的大小 |
| 样本总销售额 | `Σ r_i`，缺 `r_i` 时用 `价格 × s_i` | 样本金额规模 |
| 商品集中度 CR3 / CR5 / CR10 | 前 3 / 5 / 10 个 ASIN 销量和 ÷ 总销量 | CR10 即 TOP10 占比；判断商品头部垄断 |
| 商品 HHI | `Σ(ASIN销量占比²) × 10000` | ASIN 层面的集中度 |
| 品牌集中度 CR3 / CR5 | 前 3 / 5 品牌销量和 ÷ 总销量 | 头部品牌占比 |
| 品牌 HHI | `Σ(品牌销量占比²) × 10000` | >2500 高集中；<1500 分散 |
| 卖家集中度 CR3 / CR5 | 前 3 / 5 卖家销量和 ÷ 有卖家名样本的总销量 | 判断是不是被少数卖家把持 |
| 卖家 HHI | `Σ(卖家销量占比²) × 10000` | >2500 时竞争分再扣 3 |
| 平均价格 | `mean(价格)` | 与中位价一起看，判断价格带是否虚高 |
| TOP20 销量占比 | `前20名销量和 / 总销量` | 观察中腰部厚度 |
| 低评论竞品数 | `评论数 ≤ low_review_max` 的个数 | 默认阈值 50，代表新卖家可切入空间 |
| 低评论占比 | `低评论竞品数 / n` | 进差异化评分 |
| 月销 30–100 件竞品数 | `30 ≤ s_i ≤ 100` 的个数 | 精铺友好的证据 |
| 新品占比 | 上架时间在近 180 天内的个数 / n | 市场是否对新进入者开放 |
| 中位售价/评论/评分 | `median()` | 与均价一起用于建议定价 |

商品/品牌集中度用全部样本销量做分母；**卖家集中度只用导出里带「卖家名称」的样本做分母**，缺列时报告显示「缺失」，不会拿品牌冒充卖家。

## 精铺模式补充

爆款选品只看大市场；精铺还要挖**小市场机会**：

- 样本月销量只有 1,000 件左右，但头部不垄断。
- 多个竞品稳定月销 30–80 件。
- 搜索量稳定，无明显季节性。
- 评论数不高，新卖家有切入机会。
- 售价能覆盖 FBA、采购、物流、广告和退货。

这类市场照样进候选池。脚本里 `mid_sales_count` 和 `low_review_count` 就是为这个服务的。

## 判读阈值

| TOP10 占比 | 判读 |
|---|---|
| < 40% | 分散，切入机会较好 |
| 40%–55% | 中等，需要差异化 |
| > 55% | 头部集中，降竞争分 |

| 品牌 HHI | 判读 |
|---|---|
| < 1500 | 竞争分散 |
| 1500–2500 | 中等 |
| > 2500 | 品牌集中，降分 |

| 商品/卖家集中度 | 判读 |
|---|---|
| 商品 CR10 < 40% | 商品分散，切入机会较好 |
| 商品 CR10 > 55% | 少数 ASIN 吃掉大部分销量，降竞争分 |
| 卖家 HHI < 1500 | 卖家分散 |
| 卖家 HHI > 2500 | 被少数卖家把持，竞争分再扣 3 |
| 均价明显高于中位价 | 高价商品拉高均值，定价要看中位价 |

## 必须写进报告的提醒

1. 卖家精灵销量为估算值。
2. 样本竞品数有限，份额只代表样本。
3. 父子变体不能重复累加；脚本按父 ASIN 去重。
4. 缺数据的字段写「缺失」，不补 0。
