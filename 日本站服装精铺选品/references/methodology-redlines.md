# 精铺选品方法论红线与判定补充

来源：已合并的原 `sss-amazon-jp-apparel-research`。这些是判断口径，脚本不直接实现，分析时必须人工遵守。

## 1. 数据真实性红线

绝不：编造 ASIN/销量/价格/评论/BSR/历史趋势/市场份额；把缺失数据当 0；把样本份额说成日本站全站份额；在成本缺失时声称"确定净利润"；用模型知识或搜索结果猜测销量。

所有外部数据记录 6 要素：`source`、`collected_at`、`source_file`、`query`、`data_scope`、`confidence`。
缺失用 `缺失`/`N/A`/`Unknown`，不得补"看起来合理"的数字。数据不足的结论标记为"待验证"，不得写"确定推荐"。

## 2. 样本边界

市场规模与份额一律写明：数据来源、关键词/类目、ASIN 样本范围、去重规则、采集日期。
禁止"日本站市场份额"这种无边界表述，只能是"当前样本市场份额"。

## 3. Parent/Child 变体

- 市场分析以 Parent ASIN/商品家族为主，变体分析保留 Child ASIN。
- SellerSprite 销量若已是 Parent 级估算，不得把所有 Child 销量再加一遍。
- 只有 Child 销量独立可验证时才允许汇总，并记录 `aggregation_method`。
- 不确定时取保守值并标记数据质量问题。

## 4. 中国卖家 / 精铺型店铺识别（人工研判）

卖家身份尽量多来源验证（SellerSprite、Amazon seller/store 页、公司信息、品牌信息）。
**不能仅凭品牌名、图片风格或中文痕迹断言"中国卖家"**。分类：China / Japan / Other / Unknown。

精铺型店铺特征：SKU 数量适中、多个 ASIN 稳定销售、不依赖单一爆款、月销 30–100 的 ASIN 占比高、品类集中在相近服装细分、价格带稳定、持续上新、有产品扩展逻辑。
分析结论分三档：推荐研究 / 观察 / 不建议研究。本项依赖店铺数据导出，缺数据时标 N/A，不臆测。

## 5. 服装专项风险（每个候选逐项过）

- 尺码：数量、跨度、日本尺码适配、说明清晰度
- 版型：宽松/修身、男女差异、身材适配范围
- 面料：材质、透气、起球、缩水、透色、色牢度
- 退货主因：尺码不合、图文不符、面料预期差、色差、版型问题
- 合规：日本服装标签、纤维成分、原产国、护理标签——不得写成确定法律结论，需核验的标"需人工确认"

## 6. 利润模型

必须区分：revenue、referral fee、FBA fee、storage、inbound/first-mile、purchase cost、domestic freight、packaging、advertising、return/refund reserve、contribution profit。
任一关键成本缺失：不得填 0，不得声称确定利润，`profit_status=incomplete`。
广告费无实际数据时可给"假设场景"，但必须标注 assumption / source / not_actual。

## 7. 数据质量等级

每条关键结论附等级：A=多来源/直接导出验证；B=单一可靠来源；C=推算或部分数据；D=信息不足仅供观察。
推荐产品若关键指标为 C/D，标"待验证"，不得标"确定推荐"。

## 8. 出报告前 12 项真实性检查

```
CHECK-01 所有ASIN是否来自原始数据？
CHECK-02 所有Amazon链接是否由真实ASIN生成？
CHECK-03 是否存在虚构销量？
CHECK-04 是否存在虚构价格？
CHECK-05 是否存在缺失数据被填0？
CHECK-06 Parent/Child是否重复计算？
CHECK-07 市场份额是否明确为样本份额？
CHECK-08 历史缺失月份是否错误填0？
CHECK-09 利润是否包含关键成本缺失警告？
CHECK-10 Seller身份是否存在过度推断？
CHECK-11 结论是否记录数据来源和日期？
CHECK-12 HTML/Excel/MD三者核心数字是否一致？
```

任一关键检查失败：不得输出"分析完成"，应输出"数据质量存在问题"并列出失败项。

## 9. 淘汰规则补充

优先淘汰：目标窗口内明显严重季节性、强品牌垄断、高专利/商标风险、利润明显不足、退货风险极高、价格战严重、样本销量主要由 1–2 个 ASIN 贡献、无法确认真实需求、数据质量过低、强依赖广告但广告数据不可验证。
用户明确允许高风险时，保留为观察项而非静默删除。

## 10. 核心经营判断

最终目标不是卖得最多的产品，而是最适合长期、稳定、低风险经营的产品。
决策链：真实需求 → 目标季节窗口内稳定 → 竞争可切入 → 低评论也有销量 → 价格合理 → 利润可验证 → 退货可控 → 生命周期长 → 有差异化 → 小批量可测试 → 适合产品组合。
